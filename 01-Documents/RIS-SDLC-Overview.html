8 Security Controls
🔒 Authentication
JWT (15-min access, 7-day refresh httpOnly cookie) + bcrypt 12 rounds + TOTP 2FA + Account lockout after 10 failures
👥 Authorization
RBAC (6 roles) + PostgreSQL RLS + SQL ownership checks (supplier_id in WHERE) + Least privilege per endpoint
🔐 Encryption
AES-256-GCM for all PII at rest (names, emails, phones, bank accounts, TINs) + TLS 1.3+ in transit
💰 Dual Auth (Payments)
3-layer enforcement: Application service check + PostgreSQL CHECK constraint + Payment provider webhook verification
🛠 Input Validation
Joi schemas on every endpoint + XSS sanitization middleware + Parameterised SQL only (zero concatenation)
📊 Audit Trail
Immutable audit_logs table (DB trigger blocks UPDATE/DELETE) + 14+ entries per invoice lifecycle + 7-year retention
🛡 Rate Limiting
Per-IP + per-endpoint limits + 10 login attempts / 15 min + Helmet security headers + CORS allowlist
🌍 Compliance
Uganda FIA AML/CTR + KYC gate before funding + Sanctions screening (10s) + SAR auto-flag at 100M UGX
9 3-Layer Automated Safeguard System
L1
BLOCK
Bash Guard (mms-bash-guard.sh)
Hard-blocks destructive commands BEFORE execution: git push main, git push --force, DROP TABLE, rm -rf on financial dirs, cat .env secrets. Exit code 2 = denied.
L2
FLAG
Compliance Scanner (mms-compliance.js)
Scans every file write for 12 engineering rule violations. Financial paths (payments/, pricing/, risk-engine/, approvals/, invoices/) always require manual confirmation.
L3
FIX
Auto-Fix (mms-auto-fix.js)
Silently fixes whitespace, CRLF→LF, collapsed blank lines, EOF newlines, console.log→logger.debug, Prettier formatting. DISABLED on all financial paths.
